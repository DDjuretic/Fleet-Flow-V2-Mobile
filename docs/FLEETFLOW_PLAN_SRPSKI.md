# **FLEETFLOW EVOLUCIJA - PLAN NA SRPSKOM**

## **ŠTA PLANIRAMO?**

FleetFlow će se razviti u modularni sistem sa **3 nivoa korisnika**:

### **1. OSNOVNI KORISNICI** 📱
- **Ko su?**: Korisnici koji samo rezervuju vozila (kao postojeći Putni nalog)
- **Uređaj**: Telefon
- **Šta dobijaju**: Jednostavne rezervacije + osnovno praćenje

### **2. VOZAČI/DOSTAVLJAČI** 📱💻
- **Ko su?**: Vozači sa tabletima
- **Uređaj**: Tablet (veći ekran)
- **Šta dobijaju**:
  - **OBD-II povezivanje sa vozilom**
  - **Task Management sistem** za dostavu
  - Optimizovane rute
  - Elektronski potpis za dostavu

### **3. ADMINISTRATORI** 🖥️
- **Ko su?**: Menadžeri kompanije
- **Uređaj**: Web browser / Desktop
- **Šta dobijaju**:
  - Kreiranje zadataka za vozače
  - WMS integracija (podaci o robi)
  - Analytics i izvještaji
  - Sistemsko upravljanje
